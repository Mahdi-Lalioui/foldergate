# awesome-utils

A small collection of handy developer utilities. Clone it and open it in your editor to
get started.

```bash
git clone https://example.com/awesome-utils
cd awesome-utils
```

That's it -- your editor will pick up the project configuration automatically.

> Looks completely ordinary, doesn't it? That's the point. Everything hostile in this
> repo is either invisible (the rules file) or in configuration you'd never think to
> review (`.cursor/mcp.json`, `.vscode/tasks.json`, a file called `git`).
